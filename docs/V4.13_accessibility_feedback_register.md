# V4.13 accessibility feedback register

Source: *School Reports Accessibility Feedback.docx* (sha256 71dffd0e…), 17 Sep 2026. **Switch on** = applies only while the *Accessibility features* switch on the filter panel is on (both languages, content unchanged). **Global, invisible** = present in both modes without any visible change. The default bilingual report is pixel-identical to V4.12 outside the switch itself.

| Item | Feedback | Where it lands | What V4.13 does | Who still has an action |
|---|---|---|---|---|
| 1 | Font: Montserrat hard to read; use Aptos or Arial | Switch on | Aptos, then Arial, for all text (--fd). Default unchanged. | — |
| 2 | Font size: increase throughout; some text at 9 pt | Switch on | Body 18 px, line-height 1.6; every text style that was below 14 px (chart labels, notes, legends, rail, cards, tables, banner) raised to 16 px; headings 32/23/19 px. | — |
| 3 | Colour contrast: dark blue on light blue / on yellow | Switch on | Near-black text; yellow fields (prompts, chips, third card) pale yellow with a dark border; light-blue panels white with a dark border; small red text darkened to 6.1:1; chart track and grid darkened; chapter band dark slate with white subtitle; black focus ring. | — |
| 4 | Alt text missing on some images | Already met — verified | Every <img> carries alt text (cover logo and lockup; three character images through the ui.alt_* frames). The one decorative SVG is inside aria-hidden. The reviewer's finding is likely from the PDF export, which drops alt text from CSS-drawn content. | Translator: Welsh for the three ui.alt_* frames (pending since V4.11). |
| 5 | Chart titles not announced by screen readers | Global, invisible | Every chart card is role=group named by its own heading (aria-labelledby), so the title is announced on entering the chart; the chart body keeps its role=img description. | — |
| 6 | Chart accessibility (colours) | Switch on | Colour-blind-safe palette (Okabe–Ito): vermillion / blue / grey bars, selected value light yellow with a black outline plus the existing ✓ tick; stacked segments recoloured by position; hatched missing values kept. | — |
| 7 | Screen readers read only the first line of some paragraphs | No HTML cause found | Paragraphs are single <p> elements without line breaks; the symptom matches PDF paragraph tagging rather than the page. Not changed. | Reviewer: confirm whether this was observed in the browser or in the PDF. |
| 8 | Tables navigable by keyboard | Switch on (+ existing) | Data tables already sit behind a keyboard-operable summary; with the switch on every data table is open and focusable (tabindex 0) so keyboard and screen-reader users reach every table without a mouse. Off restores the earlier state. | — |
| 9a | Cover colours and imagery very bright | Switch on | Cover red field muted to slate; lockup and character images desaturated. | — |
| 9b | Purpose of the cover/character images unclear | Switch on | A visible caption under each character image, taken from its own alt text (frame). | Translator: as item 4. |
| 9c | Text-heavy; technical terms (e.g. 'Base'); plain English; glossary | Switch on (glossary) / raised (wording) | Glossary panel at the top of the guide listing nine terms, each a link that opens the guide's existing FAQ answer — no new definitions. The plain-English rewrite of the report's wording is owner-owned English (locked narrative, sheet 49) and was not attempted. | Owner: decide whether a plain-English pass on sheet 49 / narrative is wanted (it changes the locked English). Translator: Welsh for ui.a11y_switch, ui.a11y_glossary_heading, ui.a11y_glossary_intro. |
| 10 | PDF export cut off about a third of the way down the page | Global print rules; not reproduced | Headless Chromium prints the whole page (61/65 pages default, 108/96 with the switch on). Defensive print rules added: no clipped or scrolling ancestors, no sticky positioning, no scroll margins while printing. Screen rendering unaffected. | Reviewer: which browser and print route (Print → Save as PDF, or another tool) produced the cut-off PDF, so it can be reproduced. |
